# Demo 3: for everyone using Claude or ChatGPT chat

## Install the skill (2 minutes)
**Claude (web, desktop, mobile):** download `memory-notebook.zip` → Settings → Capabilities → Skills → Upload skill. (Code execution must be on.)
**Claude Code:** copy `memory-notebook/` into `~/.claude/skills/`.
**ChatGPT or any other assistant:** paste `memory-capsule-prompt.txt` into custom instructions or a Project's instructions.

## Live demo script (3 minutes)
1. New chat: "Remember: I'm vegetarian, my son is allergic to peanuts, and I live in Delhi."
2. "Actually we moved to Pune." → `Saved: city = Pune (was Delhi)`
3. "I'm starving." → nothing saved (it's a mood, not a fact).
4. "Save memory." → copy the MEMORY CAPSULE.
5. Open a brand-new chat, paste the capsule, ask: "Book a team dinner near me tonight."
   It picks a vegetarian, peanut-free place in Pune. Same AI, no longer a stranger.
6. Bonus: paste the same capsule into ChatGPT. Your memory is portable and yours.

## Built-in options worth turning on
- **Claude:** Settings → memory (search and reference past chats); Projects keep their own instructions and knowledge.
- **ChatGPT:** saved memories plus reference chat history; Projects can keep project-only memory.
- Both let you view and delete what is remembered. Check it monthly: one wrong entry gets trusted completely.
