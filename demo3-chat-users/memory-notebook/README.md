# memory-notebook

A Claude skill that gives Claude a versioned long-term memory: semantic facts that are
superseded (never overwritten), an episodic log, and procedural rules.

- In **Claude Code** it writes to `.memory/` in your project.
- In **claude.ai / Claude apps / ChatGPT** it keeps a portable MEMORY CAPSULE you paste into a new chat or a Project.

Try: "remember I'm vegetarian", "we moved from Delhi to Pune", "what do you remember?", "save memory".
